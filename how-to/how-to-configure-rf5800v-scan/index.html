HOW TO / Radio programming

Configure an RF-5800V scan list

Choose which nets to monitor, set the priority nets, and check the scan timing against your task.

RF-5800V-HH10–15 min5 steps
← All signal guides

BEFORE YOU START

Kit & prerequisites

Equipment
RF-5800V-HH with existing programmed nets and a coordinated test station

  • An approved list of existing nets to monitor
  • Assigned priority transmit/receive nets and timing values
  • Radio firmware/menu labels checked against the operator manual; this handout covers configuration, not the scan activation control

FIELD CHECKLIST

Follow the steps

0 of 5 steps complete

Progress is saved on this device.

  1. 01

    Build the scan list

    Press [8-PGM] → SCAN → LIST → ADD. Add each assigned existing net and confirm with Enter. The source uses Net 01 only as an example.

    Verify Every intended net is included and unrelated nets are absent.

  2. 02

    Set the priority transmit net

    Open PRIORITY and set Priority TX to the assigned net. Do not assume the currently heard net is the transmit destination.

    Verify The priority TX entry agrees with the communication task.

  3. 03

    Set priority receive monitoring

    In PRIORITY, set Enable Priority RX and Priority RX Net as assigned. The source example enables priority reception on Net 02.

    Verify Priority reception is enabled only when required, with the correct net selected.

  4. 04

    Configure the timing

    Open CONFIG. Set Hang Time, enable Hold Time if required, and set its duration. The slide illustrates 3 seconds and 9 seconds; use your assigned values. It repeats the label “Enable Hold Time” for the duration line, so verify the actual field label on your radio.

    Verify The enable choice and duration are checked separately; the example timings have not been treated as defaults.

  5. 05

    Review the configuration and test monitoring

    Reopen LIST, PRIORITY and CONFIG to confirm the saved entries. Use the applicable operator-manual control to activate scanning; that control is not shown in this excerpt. With a partner, make identified test calls on the listed nets and confirm reception.

    Verify Record which test nets were heard and whether priority reception behaved as intended.

VERIFICATION

Done when

The scan list, priority entries and timing match the task, and the coordinated monitoring test is recorded.

FIELD DIAGNOSIS

Troubleshooting

An expected net is not heard
Check that the net exists, is in LIST, and scanning is active using the applicable operator manual.
Priority traffic is missed
Check Enable Priority RX and Priority RX Net before changing unrelated settings.
The radio appears to linger after traffic
Review Hang Time and Hold Time against the assigned values; use the operator manual for their exact firmware-specific behavior.

Watch for Adding a net to the list is not proof that scanning has been activated. The supplied three procedure slides do not identify the activation control.
