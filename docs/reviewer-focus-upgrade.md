# Exam-focused reviewers and LOS visual — 8 November 2026

All 32 lesson reviewers now begin with a clear takeaway and sourced key-point cards, followed by contrasts and objective/analytical question styles. Full explanations, scenarios, existing practice and references remain accessible. The new material uses the existing lesson-grounded topics and facts; it does not expand examinable scope to supplementary manuals.

Question styles are explicitly practice inferences, not claimed knowledge of an instructor's exam. Each answer includes reasoning and page links. Recall mode closes the key-point answers so students can explain the concept before revealing it. Missing browser storage does not prevent reading or using the controls.
